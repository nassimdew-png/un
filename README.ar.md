# 🧠 PsyPro Tech (المنصة السريرية لإدارة العيادات النفسية والأرطوفونية)

منصة سحابية متكاملة (SaaS) موجهة للأخصائيين النفسانيين، الأرطوفونيين، والمراكز العلاجية، توفر إدارة شاملة للمرضى، بنوك روائز مقننة، تمارين علاجية، وتكاملات متقدمة للذكاء الاصطناعي السريري.

---

## 🛠️ البنية التقنية (Tech Stack)

* **Backend:** Laravel 11 (PHP 8.2+), Laravel Sanctum (Token Authentication), MySQL Database.
* **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, Axios, Zustand.
* **Infrastructure & Server:** Ubuntu Linux VPS, Nginx, PM2 Process Manager, SSL (Let's Encrypt).
* **AI Integrations:** Google Gemini 1.5/2.0, DeepSeek V3/R1, OpenAI GPT-4o.

---

## 🧩 الوحدات الأساسية للمنصة (Core Modules)

### 1. بنك الروائز والمقاييس التشخيصية (`/clinical-tests`)
* مقاييس مقننة عربياً وجزائرياً (BDI-II, CARS-2, Conners-3, SSI-4, PCC).
* تصحيح آلي فوري، وتوليد تقارير نفسية ولغوية بضغطة زر.
* دعم وضع التابلت (`/tablet/kiosk`) لتمرير الروائز للمريض مباشرة.

### 2. بنك التمارين والكراسات العلاجية (`/exercises-bank`)
* بطاقات مخارج الأصوات وتدريبات النطق مع مشغل صوتي تفاعلي.
* كراسات وأوراق عمل قابلة للطباعة PDF (متاهات، تهيئة للكتابة، إدراك بصري).
* بطاقات التواصل بالصور (PECS) والقصص الاجتماعية.
* نافذة إسناد الواجبات المنزلية لملف المريض.

### 3. إدارة العيادة والملف الطبي الإلكتروني (EMR)
* إدارة ملفات المرضى والأطفال، السجل الطبي والملاحظات السريرية (SOAP).
* جدولة المواعيد، قائمة الانتظار، وشاشة الاستقبال الذكية (Kiosk Mode).
* الفوترة وسندات القبض، مع دعم وسائل الدفع المحلية (BaridiMob / CCP).

### 4. لوحة تحكم السوبر أدمن (Super Admin)
* إدارة تراخيص واشتراكات العيادات وتحديد الحصص (Quotas).
* مركز إدارة مفاتيح الذكاء الاصطناعي واختبار الاتصال اللحظي.
* بوابات التواصل (WhatsApp Cloud API, SMS, SMTP).
* مفاتيح تشغيل وإيقاف الميزات العامة (Feature Master Switches).

## 🛡️ بروتوكول التطوير والعمل الآمن (Git Workflow)

لضمان استقرار السيرفر الحي وتفادي فقدان الملفات:

1. **الفرع الرئيسي (`master`):** مخصص للنسخ المستقرة المعتمدة فقط.
2. **فروع الميزات (`feature/*`):** يتم بناء واختبار كل ميزة بشكل معزول تماماً.
3. **قواعد صارمة:**
   * يُمنع تشغيل `git reset --hard` أو `npm audit fix --force` على بيئة الإنتاج.
   * يتم فحص البناء (`npm run build`) وتفريغ الكاش قبل كل دمج (Merge).

## 🚀 أوامر التشغيل والصيانة السريعة

```bash
# تنظيف وتحديث كاش الباك إند
cd /var/www/clinic-saas/backend
php artisan optimize:clear

# بناء حزم الواجهة
cd /var/www/clinic-saas/frontend
npm run build

# إعادة تشغيل العمليات
pm2 restart all
```
