# 🏥 PsyPro (ClinicSaaS) — المنصة السحابية المتكاملة لإدارة عيادات ومراكز علم النفس والأرطوفونيا

> **نظام طبي إكلينيكي متقدم متعدد المستأجرين (Multi-Tenant Clinical SaaS)**  
> مصمم خصيصاً لأطباء وممارسي **علم النفس العيادي (Psychologie)**، **الأرطوفونيا والتخاطب (Orthophonie)**، و**التأهيل النفسي-حركي (Psychomotricité)**.

---

## 🌟 أبرز موديولات ومميزات المنصة (Core Modules)

### 1️⃣ قمرة الجلسة السريرية المباشرة (Active Consultation Workspace)
بيئة عمل طبية هادئة (Zen Mode) مصممة بمسار سريري مرحلي من 4 خطوات:
* **المرحلة 1 (الاستقبال والمزاج والخط الأساسي)**:
  - تحديد التخصص السريري (أرطوفونيا / علم نفس / نفسي-حركي).
  - لوحة المقارنة التطورية التراكمية مع أول جلسة للمريض (Baseline Comparison).
  - استعراض ملخص الجلسة السابقة مع إمكانية استيراد أهدافها بنقرة واحدة.
  - المسح الانفعالي ومزاج البداية (Humeur & Affect) وشكوى المقابلة.
* **المرحلة 2 (قمرة التدخل والأدوات السريرية المتخصصة)**:
  - **مقياس شدة الضيق والتوتر اللحظي (SUDS Scale 0-100)** قبل وبعد التمرين مع حساب نسبة التحسن.
  - **سجل إعادة الهيكلة المعرفية (CBT Thought Record)** لرصد التشوهات المعرفية وصياغة البدائل العقلانية.
  - **مصفوفة فحص النطق الصوتي (Phonetic Matrix)** للفونيمات ومواضعها ونوع الاضطراب.
  - **راصد المحاولات ودقة النطق اللحظية (`%`)** بأزرار لمس سريعة وردود فعل صوتية.
  - **ميترونوم الطلاقة والتنفس الإيقاعي** لضبط سرعة الكلام وعلاج التأتأة.
  - **مسودة الملاحظات العفوية السريعة (Live Scratchpad)** لتدوين الملاحظات الحية ودمجها بضغطة زر في تقرير SOAP.
* **المرحلة 3 (التوثيق السريري الذكي SOAP)**:
  - **مساعد الإملاء الصوتي الذكي (AI Voice Scribe)** بالدارجة الجزائرية، العربية الفصحى، أو الفرنسية.
  - **نماذج سريرية جاهزة بنقرة واحدة** لتعبئة حقول SOAP الأربعة فوراً.
  - **أهداف الخطة العلاجية الفردية (PEI Goals)** المخصصة ديناميكياً لكل تخصص مع إمكانية إضافة أهداف جديدة وتصنيفها كـ (مكتسب / قيد التدريب / تعزيز).
* **المرحلة 4 (الإنهاء والإحالات والفوترة)**:
  - **الإحالات والتوجيهات الطبية المتخصصة** (ORL, EEG, Audiométrie, Neuro, Psych, Pédiatrie).
  - **إرسال تقرير الواجبات والتوصيات للولي عبر WhatsApp** بنقرة واحدة.
  - **إصدار وصل القبض والفوترة** (DZD).
  - **حفظ واعتماد التقرير السريري** في قاعدة البيانات وتحديث الموعد.

### 2️⃣ محرك المقاييس والاختبارات الرقمية المعيارية (+18 رائز معتمد)
- **قائمة المقاييس المعيارية النشطة**:
  - `PHQ-9` (صحة المريض - الاكتئاب)
  - `GAD-7` (مقياس اضطراب القلق العام)
  - `BDI-II` (مقياس بيك للاكتئاب - الإصدار الثاني)
  - `HAM-A` (مقياس هاملتون للقلق)
  - `HAM-D` (مقياس هاملتون للاكتئاب)
  - `PCL-5` (اضطراب ما بعد الصدمة PTSD)
  - `DASS-21` (الاكتئاب والقلق والضغط النفسي)
  - `CARS-2` (تقدير التوحد الطفولي 2)
  - `M-CHAT-R/F` (الكشف المبكر عن التوحد)
  - `SNAP-IV` (فرط الحركة وتشتت الانتباه TDAH)
  - `Y-BOCS` (الوسواس القهري ييل-براون)
  - `SPIN` (الرهاب والقلق الاجتماعي)
  - `PDSS-SR` (شدة نوبات الهلع)
  - `ISI` (مؤشر شدة الأرق واضطراب النوم)
  - `ASRS` (أعراض تشتت الانتباه للبالغين)
  - `AQ-10` (طيف التوحد الموجز للبالغين)
  - `PSS-10` (الضغط النفسي المدرك)
  - `RSES` (روزنبرغ لتقدير الذات)
- **ميزة التمرير المباشر في الجلسة**: يستطيع المعالج فتح أي مقياس وتمريره مع المريض وتُدرج النتيجة والدرجة الخام والتفسير الإكلينيكي تلقائياً في خانة `Objective` في تقرير SOAP!
- **البوابة الرقمية للمريض عبر الهاتف أو التابلت**: إرسال رابط مشفر أو رمز QR للمريض لتعبئة المقياس ذاتياً بدون كلمة مرور.
- **رصد الأمان السريري الفوري (Red Alert)**: كشف فوري لأي أفكار إيذاء نفس ووسم التقرير بـ `🚨 [تنبيه أمان سريري عاجل - RED ALERT]`.

### 3️⃣ قمرة الأجندة والمواعيد السريرية المتطورة (Clinical Agenda & Cockpit)
- **4 زوايا رؤية تفاعلية**:
  - `جدول الحصص اليومي (Timeline)`: خط زمني تفصيلي بالساعة (من 08:00 إلى 18:00) مع بطاقات المرضى، سبب الاستشارة، وإجراءات الجلسة السريعة.
  - `شبكة الأسبوع (Weekly Grid)`: مصفوفة بـ 7 أعمدة (من السبت إلى الجمعة) مع حجز وتعديل المواعيد بنقرة واحدة.
  - `التقويم الشهري (Monthly Calendar)`: كثافة الحصص الشهرية والقفز السريع لليوم.
  - `القائمة التفصيلية المتقدمة (Advanced List)`: بحث فوري وفلترة دقيقة حسب الطبيب/المعالج والحالة السريرية.
- **قمرة قاعة الانتظار والبورن الرقمي المباشر**:
  - كشف الحضور اللحظي ووسم المريض بـ `🟢 حاضر بقاعة الانتظار` فور تأكيد الحضور عبر الـ Kiosk PIN.
  - نداء المريض الصوتي (Audio Chime + Arabic Speech Announcement).
- **الربط المباشر بقمرة الجلسة السريرية**:
  - زر فوري **"بدء الجلسة السريرية" (Lancer la séance)** لإطلاق مسار الجلسة بملء الشاشة مع الميقاتية التراكمية.
- **النافذة الذكية للحجز والجدولة (`AppointmentModal`)**:
  - كشف التعارضات التلقائي (Double-Booking Conflict Warning).
  - برنامج الحصص المتكررة أسبوعياً (Reconduction Hebdomadaire).
  - إرسال تذكير WhatsApp رسمي وفوري للمريض.
  - صندوق استقبال طلبات الحجز من الدليل الوطني للعيادات.

### 4️⃣ محرك الحصائل والتقارير الطبية الرسمية (Automated Clinical Bilan & PDF Engine)
- **تجميع السجل السريري الشامل**:
  - سحب التاريخ النمائي والولادي (Anamnèse).
  - شجرة العائلة والقرابة الوراثية (Génogramme Clinique).
  - خريطة الجسد والأعراض والملف الحسي (Sensory Body Map).
  - نتائج المقاييس الرقمية الـ 18 المعيارية مع الدرجات والشدة وتنبيهات الأمان (Red Alerts).
  - ملاحظات SOAP وأهداف الخطة العلاجية الفردية (PEI Goals).
- **المحرر السريري الذكي (`MasterBilanBuilderModal.jsx`)**:
  - مسار متسلسل من 3 خطوات للصياغة بالعربية والفرنسية.
  - زر استيراد فوري بنقرة واحدة من ملاحظات آخر جلسة SOAP.
  - مصفوفة أهداف PEI مع أوسمة الاكتساب (🟢 مكتسب / 🟡 قيد التدريب / 🔴 تعزيز).
- **توليد وثيقة PDF الطبية الرسمية والتسليم**:
  - معالجة النصوص وتشكيل الحروف العربية عبر `ArabicPdfService` ومكتبة `ArPHP`.
  - ترويسة عيادية رسمية كاملة مع خاتم وتوقيع الطبيب وعبارة السر المهني.
  - تنزيل وطباعة مباشرة بجودة A4، ومشاركة إشعار الحصيلة مع الولي عبر WhatsApp بنقرة واحدة.

---

### 5️⃣ محرر المقاييس البصري للسوبر أدمن (Super Admin Builder)
- واجهة متكاملة من 4 تبويبات لتحرير كتالوج المقاييس:
  1. `البيانات التعريفية والتعليمات`: الرمز، التخصص، والتعليمات بالعربية والفرنسية.
  2. `بنود الأسئلة والخيارات`: إضافة وحذف الأسئلة وتحديد درجات الخيارات.
  3. `قواعد حساب الشدة (Severity Rules)`: مجالات الدرجات، الألوان، والتوصيات السريرية.
  4. `تنبيهات الخطر السريري (Red Alerts)`: تعيين بنود الأمان وقيم الاستجابة المحفزة للتنبيه العاجل.

---

### 6️⃣ قمرة القيادة والسيطرة للسوبر أدمن (SuperAdmin Pro Suite)
- **قمرة السيطرة والسيادة (`SovereignControlTower`)**: وضع الصيانة العام، حجر العيادات، وتعديل الميزات وحصص الذكاء الاصطناعي لكل عيادة فوراً.
- **خريطة انتشار العيادات الوطنية (58 ولاية)**: محرك جغرافي تفاعلي يغطي كامل القطر الجزائري مع مؤشرات الكثافة الطبية ومطابقة الإحداثيات الآلية.
- **محرك الكوبونات والإحالات وشراكات الأطباء**: توليد أكواد الخصم، متابعة برامج السفراء، وحساب العمولات مع أرشفة مدفوعات BaridiMob.
- **دورة الاشتراكات ومطابقة الدفع**: متابعة مواعيد التجديد، إرسال تذكيرات WhatsApp، وصندوق إيصالات الدفع للاعتماد بنقرة واحدة.
- **صحة السيرفر وخدمات PM2 (Live Telemetry)**: متابعة حية لاستهلاك الموارد والذاكرة وعمليات PM2 مع أزرار التحكم الفورية.
- **أستوديو توجيه الذكاء الاصطناعي (AI Routing & Cost Studio)**: الربط مع مزودي الذكاء الاصطناعي (Groq, OpenAI, Gemini...)، تفعيل شلال التبديل التلقائي، وتتبع تكلفة الـ Tokens.

## 🏛️ البنية التحتية والتقنيات (Tech Stack)

- **الواجهة الأمامية (Frontend)**:
  - React 18 + Vite (PWA)
  - Tailwind CSS + Lucide Icons
  - Web Audio API (تأثيرات صوتية ونغمية طبية)
  - Web Speech API (إملاء وتفريغ صوتي)
  - دعم كامل للغة العربية (RTL)
- **الواجهة الخلفية (Backend)**:
  - Laravel 11 / PHP 8.2+ RESTful API
  - MySQL / MariaDB Engine
  - Laravel Sanctum Authentication
- **خادم الإنتاج السحابي (Production VPS)**:
  - العنوان: `145.223.116.54`
  - المسار: `/var/www/clinic-saas/`
  - مدير العمليات: `PM2` (`clinic-backend` ID 0، `clinic-frontend` ID 1، `clinic-queue` ID 2)

## 🚀 أوامر التشغيل والنشر (Operations & Deployment)

```bash
# تشغيل الفرونت إند محلياً (Dev)
cd frontend && npm run dev

# بناء الواجهة الأمامية (Build)
cd frontend && npm run build

# تشغيل الباك إند محلياً
cd backend && php artisan serve

# تنظيف كاش لارفيل:
php artisan optimize:clear && php artisan config:clear && php artisan route:clear

# نشر التحديثات المجمعة على خادم الإنتاج (VPS) عبر الأرشيف السريع:
python deploy_superadmin_archive.py

# أو يدوياً عبر SSH على السيرفر:
cd /var/www/clinic-saas/backend && php artisan optimize:clear && php artisan migrate --force
cd /var/www/clinic-saas/frontend && npm run build
pm2 restart 0 && pm2 restart 1 && pm2 restart 2
```
